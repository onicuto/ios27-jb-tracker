# Архив фактчекинга джейлбрейка iOS 27.0.1 · Инструкция по использованию навыка

[Русский](SKILL.md) | [中文版](SKILL_ZH.md)

## Порядок загрузки материалов
1. Сначала прочитайте `README.md` (или `README_ZH.md`) для получения общей структуры выводов (главные выводы в трёх пунктах, ошибки E1–E3, корректировки P1–P6, умолчания O1–O3, правила выявления скама).
2. В зависимости от типа вопроса переходите к детальным разделам:
   - Вопрос: «Реально ли событие / детали демонстрации Calif» → `report/full-audit-zh.md` (Глава 2)
   - Вопрос: «В чём ошибки разошедшегося отчёта» → `report/full-audit-zh.md` (Глава 3: E1–E3, P1–P6)
   - Вопрос: «Возможен ли джейлбрейк для моего устройства» → `report/full-audit-zh.md` (Глава 4) + поиск O1 в `data/claims.json`
   - Вопрос: «Стоит ли обновляться на iOS 27» → `report/full-audit-zh.md` (Глава 5, дерево решений)
   - Вопрос: «Что известно про AstraSaw / фейки / скам» → `research/astrasaw-audit.md` (или `research/astrasaw-audit-zh.md`) + `README.md` (раздел «⚠️ Распознавание скама») + утверждения V21–V28 в `data/claims.json`
   - Вопрос: «Что за скриншоты root от Din3zh» → утверждение V29 в `data/claims.json` (продолжение линии usbliter8/A13, ошибка интерпретации СМИ)
   - Вопрос: «Откуда взято конкретное утверждение» → найдите claim в `data/claims.json` и проверьте номер источника в библиографии `report/full-audit-zh.md`
3. При необходимости первоисточников и логов обращайтесь к исследовательским файлам в папке `research/` (dim01–dim10, инцидент с iPhone Duo, досье AstraSaw).
4. Терминологию сверяйте с глоссарием `CONTEXT.md` (или `CONTEXT_ZH.md`).

## Правила формирования ответов
- При ссылке на факты обязательно приводите номера источников из отчёта (`[^N^]` ↔ 127 источников в конце отчёта) и указывайте временную отсечку данных.
- Строго разделяйте 4 уровня вердикта: подтверждено (属实) / частично подтверждено (部分属实) / не подтверждено (无法证实) / опровергнуто (证伪); предположительные выводы обязательно помечайте словом «предположительно/вывод».
- События продолжают развиваться: перед ответом проверьте `CHANGELOG.md` и `data/timeline.json` на наличие свежих записей.
- Данный архив — материал для фактчекинга: **не предоставлять и не рекламировать способы получения инструментов для взлома**; на вопросы о сроках релиза инструментов ссылаться исключительно на официальные комментарии авторов (write-up после прекращения подписи 27.1).
